# Identidade visual IaBrain

A nova marca representa o **cérebro por trás das IAs**: um cérebro tecnológico abstrato formado por estruturas cristalinas, circuitos e um núcleo central de processamento.

## Arquivos

| Arquivo | Uso |
|---|---|
| `iabrain-symbol.png` | Fonte transparente em alta resolução para apresentações, exportações e novas composições. |
| `../app/src/main/res/drawable-nodpi/ic_logo.png` | Símbolo transparente otimizado para a tela de carregamento e a tela de boas-vindas. |
| `../app/src/main/res/mipmap-*/ic_launcher*.png` | Ícones legados do Android em densidades mdpi a xxxhdpi. |
| `../app/src/main/res/mipmap-xxxhdpi/ic_launcher_foreground.png` | Foreground do adaptive icon Android, com margem segura para máscaras circulares e arredondadas. |
| `prepare_brand_assets.py` | Script reexecutável que gera as cópias Android a partir da fonte transparente. |

O wordmark **IaBrain** é renderizado como texto nativo no Android para preservar legibilidade, acessibilidade e proporções consistentes em diferentes densidades.
